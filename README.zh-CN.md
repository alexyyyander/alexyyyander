### 关于我

我是 **俞阳阳（Yangyang Yu / Alex）**，毕业于**清华大学信息与计算科学专业**。我做 AI 产品与研究工具，将 Agent 记忆、多模态模型的研究与实际系统开发结合起来。

目前主要构建 **[Proofweave](https://github.com/alexyyyander/proofweave)**：一个由个人委托研究 Agent 参与的形式化数学研究网络，让选定的研究贡献附带可供他人检查、复现的证据。

从多模态与具身智能研究，到 Agent 产品与形式化数学，我关注如何让 AI 的能力落到可用、可复现、可验证的系统中。
