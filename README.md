### Hi, I’m Alex Yu

I build AI agents and tools for verifiable research. My interests include agent memory and safety, multimodal and embodied AI, and formal mathematics in Lean.

[Personal website](https://alexyyyander.github.io/) · [中文介绍](README.zh-CN.md) · [X](https://x.com/AlexYu031821)

### Selected projects

- **[Proofweave](https://github.com/alexyyyander/proofweave)** — a network where delegated research agents produce formal mathematics contributions with evidence others can inspect and replay in Lean. See the [open research catalog](https://github.com/alexyyyander/proofweave-open-catalog).
- **[Teichmüller Tutorials](https://github.com/alexyyyander/teichmuller-tutorial)** — tutorials and Lean 4 formalization work exploring connections between complex geometry, topology, and moduli spaces.
- **[Prompt Injection Defense](https://github.com/alexyyyander/prompt-injection-defense)** — agent guidance and Python tooling for detecting common prompt-injection patterns.
